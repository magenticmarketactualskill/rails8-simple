# Rails 8 Simple Application

A simple Rails 8 application created as an example for git-template development and testing.

## Features

- Rails 8.0 application structure
- Basic MVC setup
- Git-template configuration included
- Suitable for template development and testing

## Usage

This application serves as:
- A reference implementation for Rails 8 applications
- A base for git-template development
- An example of template configuration structure

## Template Development

This application includes a `.git_template` directory with:
- Template configuration (`template.rb`)
- Test responses for automated testing
- Module organization structure

## Getting Started

1. Clone this repository
2. Run `bundle install`
3. Run `bin/rails server`
4. Visit `http://localhost:3000`

## Git Template Integration

Use with git-template commands:

```bash
# Check status
git-template status .

# Iterate on template development
git-template iterate .

# Update template configuration
git-template update .
```
